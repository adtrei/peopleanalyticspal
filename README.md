# People Analytics Gap Intelligence Engine

## Overview

This application analyzes workforce data to determine:
- What we know
- What we don’t know
- What we cannot know

It is a decision-support system focused on truth and clarity.

---

## Features

- CSV Upload
- Schema Mapping
- Gap Detection
- AI Analysis
- Executive Outputs

---

## Architecture

Frontend: React / Next.js  
Backend: Node or Python  
AI: OpenAI API  
Storage: Local -> Supabase  

---

## Getting Started

1. Clone repo
2. Install dependencies
3. Add OPENAI_API_KEY to .env
4. Run app
5. Upload data

---

## Outputs

- Question Coverage Table
- Gap Map
- Known vs Unknown Summary

---

Truth over completeness.
Clarity over complexity.
